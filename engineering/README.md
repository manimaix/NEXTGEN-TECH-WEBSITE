# Nextgen Tech Sdn Bhd — junior engineering assignment pack

Baseline v1.0 · Proposed implementation · Owner: Ryan · 22 September 2026

Build a credible service website for consulting, application development, AI agent deployment/integration, and AI training. The primary successful journey is an enquiry durably received and accessible to authorised staff.
