## Design direction

White and pale grey surfaces, dark ink, restrained blue actions, compact desktop navigation, readable system-style typography, careful alignment, useful information and complete footers. Impeccable guided hierarchy and section composition; Emil's guidance informed clear controls, restrained states and consistency. The images do not demonstrate live motion or accessibility compliance.

Marketing pages use actual Nextgen Tech service categories. All application examples and staff records are illustrative. Privacy and website-information copy remains draft material for review. Page layouts and some copy are visual proposals, not a verified specification of current backend behavior. Staff deep-path labels identify design views within the existing admin area.

## Files and generation

- Main numbered PNGs: final **1080 × 1920** exports.
- `native/`: unmodified generated images, retained at the image tool's native resolution.
- `generation-manifest.json`: exact prompts, reference-image paths and output provenance.
- `export-portrait.ps1`: mechanical image-size export only; all visual generation was performed with built-in ImageGen.
- `verification.json`: verified pixel dimensions and file sizes.
- `index.html`: local gallery, no external libraries or internet required.

The generator returned near-9:16 files (typically 941 × 1672). Final PNGs are resampled to the requested exact 1080 × 1920; they are not claimed as native 1080p generation. No cropping or layout stretching from the superseded landscape concepts is used. Each portrait page was freshly generated.

Application source files were not changed.
